# Hospital Escape

A small browser game for iPhone (and any other browser). Your shift ended at 17:00. Guide the doctor from floor 5 down to the staff parking lot without running into:

- **Patients** with "one quick question"
- **Family members** who want an update and follow you
- **Attendings** who patrol the halls, see ahead of them, and hand out weekend shifts
- **The Chief of Medicine**, who always knows where you are

Pick up **coffee** to walk faster and a **clipboard** to look busy (nobody stops you while it lasts). Three run-ins and you burn out. Every second costs a minute of overtime; try to beat your best escape time.

## Play

Open `index.html` in a browser. It's a single file with no build step.

- **iPhone:** drag anywhere on the floor plan to walk. Host the file (for example with GitHub Pages), open it in Safari, then use Share → Add to Home Screen to play full screen.
- **Keyboard:** arrow keys or WASD.
